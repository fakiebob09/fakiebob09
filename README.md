# Портфолио Игоря Плотникова (Concept Artist & Illustrator)

Атмосферный авторский сайт-портфолио концепт-художника и иллюстратора с интерактивной галереей, фильтрами, админ-панелью для управления проектами и заявками.

## Запуск локально

1. Установите зависимости:
```bash
npm install
```

2. Запустите сервер разработки:
```bash
npm run dev
```

3. Для сборки production-версии:
```bash
npm run build
```

## Автоматическая публикация на GitHub Pages

В репозиторий уже добавлен готовый workflow `.github/workflows/deploy.yml`.

Чтобы активировать бесплатный хостинг:
1. Загрузите файлы в ваш репозиторий на GitHub.
2. В репозитории перейдите в **Settings** -> **Pages**.
3. В разделе **Build and deployment** -> **Source** выберите **GitHub Actions**.
4. Сайт автоматически соберется и опубликуется на вашем адресе `https://<username>.github.io/<repo-name>/`.
